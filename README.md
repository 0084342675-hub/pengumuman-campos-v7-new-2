# V7.2 — Pengumuman Open Recruitment MPK - OSIS SMA Negeri 10 Depok 2026

## Form peserta
Urutan:
1. Nama Lengkap
2. Kelas — X.1 s/d X.11 atau XI.1 s/d XI.9
3. Tahun Lahir — 2000 s/d 2026
4. Pilihan — MPK / OSIS

Keempat data harus cocok dengan CSV.

## Update data peserta
Edit hanya `data/peserta.csv`.

CSV dimulai dengan:
- `tahun_lahir`
- `status`
- `judul`
- `keterangan`

Lalu kolom tabel:
No, Nama, Kelas, Jenis Kelamin, Pilihan, Skolastik, seluruh rincian nilai, Jumlah Nilai, Keterangan.

`status`:
- `blue` = lolos
- `yellow` = lolos bersyarat
- `red` = belum lolos

## Tabel
Tabel rincian nilai muncul DI BAWAH kartu pengumuman.
Di HP tabel dapat digeser ke kanan/kiri agar semua kolom tetap terbaca.
Header dibuat menjadi grup:
Keagamaan Islam, Keagamaan Kristen & Katolik, Public Speaking, Wawancara.

## Foto
Masukkan foto ke folder `assets/` dengan nama:
`sekolah.jpg`, `mpos.jpg`, `galeri-1.jpg` sampai `galeri-6.jpg`.

CSV bawaan hanya berisi 3 data testing. Ganti dengan data peserta asli sebelum digunakan.
